Write normally. A blank line starts a new paragraph.

## A section heading

Use `##` for sections and `###` for sub-sections. **Bold** and *italic* work as you would expect, and so do [links](https://kopitiam.lol).

- Bullet lists like this
- One item per line

1. Numbered lists too
2. Same idea

> A blockquote, for pulling out a line you want to emphasise.

To add an image, drop the file into `content/images/` and reference it by filename.
The alt text doubles as the caption shown under the image:

![Uncle Lim yelling about a slow order](images/uncle-lim-screenshot.jpg)

`Inline code` uses single backticks, and a fenced block uses triple backticks:

```
git commit -m "fix: the Serve button again"
```

Notes:
- Any file starting with `_` is ignored by the build.
- `draft: true` keeps a post out of the blog index and the RSS feed. Remove it to publish.
- The filename becomes the URL, minus a leading date: `2026-09-01-my-post.md` becomes `/blog/my-post/`.
